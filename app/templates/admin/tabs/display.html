Banners

{{ section_error("banners") }}

An event's own popup reminder sets how early it shows (at most 2 hours); the minutes here are for events without one. Quiet hours show no banners and play no sound. They're separate from night colours, so a 19:30 club still gets its banner.

Chimes: the tablet keeps sound off until someone touches the screen after the display loads, so banners before that show without a chime. In Fully Kiosk, Web Content Settings → Autoplay Audio may let it start sooner.

Idle screen

{{ section_error("idle") }}
When nobody has touched the wall for a while {% for value, label in idle_modes.items() %} {% endfor %}
At night {% for value, label in idle_modes.items() %} {% endfor %}

Leave both night times blank to follow Appearance (night colours). The slideshow shows the time, the next event today and the weather; with no photos chosen it's a calm clock. The first tap on an idle wall only wakes it. It never goes idle while someone is typing, dragging or has a list open, or just after a banner appears.

Set up Fully Kiosk to match (Fully PLUS is needed for real dimming: without it the wall dims with a dark overlay and the backlight stays on):

  • Turn off Fully's own screensaver and its screen-off timer. Huddle does idle itself.
  • For overnight screen-off, set Fully's own wake/sleep schedule (Device Management → Scheduled Wakeup/Sleep). A screen Fully has turned off doesn't wake on a tap, so keep that for the night only.
  • Enable Fully's JavaScript Interface (Advanced Web Settings) so Huddle can lower the brightness.
