# v1.1: setup checklist

v1.1 adds:
- Admin tabs
- school term dates
- widget show/hide
- task groups and quick add
- the notification banner
- the idle screen with photos

Deploying it needs nothing extra. The steps after that switch on the optional parts. Admin sections
are named as they appear, as **Tab → Section**.

- [ ] 1. Deploy v1.1
- [ ] 2. Fully Kiosk: buy PLUS and adjust its settings
- [ ] 3. Enter term dates (or import the school's PDF)
- [ ] 4. Choose which widgets show
- [ ] 5. Set up task groups
- [ ] 6. Adjust the banners
- [ ] 7. Photos for the idle screen (second Google project)
- [ ] 8. Set up the idle screen
- [ ] 9. When the new tablet arrives

---

## 1. Deploy v1.1
From the repo folder on the G10:
```
git pull
docker compose up -d --build
```
Take a database snapshot first, or ask Claude to do it.

On first start the database is upgraded:
- **The Photos placeholder widget is removed.** The empty space it leaves under Weather can be
  filled by dragging Weather's corner.
- **Nothing else in your data or layout changes.** A dry run on a copy of the live database
  confirmed this.

Then reload the tablet. If a new version ever fails to start, see README → "If the app won't
start after an update".

## 2. Fully Kiosk (on the tablet)
1. Buy **Fully Kiosk PLUS** (€7.90, one-off per device). It gives Huddle real screen dimming.
2. In Fully Kiosk's settings:
   - **Screensaver: off.** Huddle runs its own idle screen.
   - **Screen off timer: off.**
   - **Scheduled wake/sleep:** set an overnight screen-off, e.g. 22:30–06:30. A screen that Fully
     has switched off **doesn't wake on a tap**, so use this only for overnight.
   - Keep Fully awake: exclude it from battery optimisation and "sleeping apps".
   - Optional: **Autoplay audio**. It may let banner chimes play without a tap first.
3. On the tablet, turn on **battery protection** (charge limit about 80–85%), because it's on
   charge 24/7.

More detail: README → "Kiosk browser setup".

## 3. Term dates (School → Term dates)
- Add each term, half term, holiday and INSET day for 2026–27. You can also upload the school's
  term-dates PDF in **School → Add from Classroom**, then check and approve the dates in
  **School → School inbox**.
- **Bank holidays** (England and Wales) come from GOV.UK automatically.
- Term dates drive the **"school days"** options (tasks and widgets), and they show on the
  calendar as striped bars. They're never added to Google.
- Admin warns you when a school year is missing or incomplete. Check the dates once a year.

## 4. Widgets (Display → Widgets)
- **Show**: hide a widget you don't use. The widgets below it move up, and showing it again puts
  it back where it was.
- **School days only**: e.g. Homework and Practice words disappear at weekends and in the holidays.

## 5. Tasks (Family → Task Schedules)
- Give tasks a **Morning / After school / Evening** group. The current group shows first on the
  wall. The group start times are also set here.
- The **"School days"** repeat option sits next to the Mon–Sun chips.
- On the wall, **"+ Add"** adds a quick one-off task. It syncs to Google if that person has a list.
- Tasks for someone with no Google list show a small "on this display only" icon.

## 6. Banners (Display → Banners)
There are four triggers, all on by default, and each can be switched off or given a chime:
- events starting soon (uses your Google reminder, up to 2 h ahead, default 30 min)
- homework due
- today's school events
- chores still to do once Evening starts

**Quiet hours** default to 21:00–07:00: no banners and no chimes then. Tap a banner to dismiss it.

## 7. Photos for the idle screen (Display → Photos)
Photos come from a **personal** Google account, which needs its own small Google Cloud project,
because the main one is Workspace-only. Follow **README → "Photos for the idle screen"**. In short:
1. Create a new Cloud project, **External / Testing**, with your personal account as a **test
   user**.
2. Enable the **Google Photos Picker API**.
3. Create an OAuth client and add `GOOGLE_PHOTOS_CLIENT_ID` and `GOOGLE_PHOTOS_CLIENT_SECRET` to
   `.env`, then `docker compose up -d`.
4. In **Display → Photos**, sign in. Do this on `localhost` on the G10, or through the SSH tunnel,
   as with the main Google connection.
5. Tap **Choose photos**, scan the QR code with your phone (signed in to the personal account) and
   pick up to **30** photos. Huddle copies them.

Good to know:
- "Testing" mode's 7-day sign-in expiry doesn't matter, because Huddle only uses the sign-in while
  you choose photos. You may just need to sign in again next time.
- The photos reshuffle weekly and are **not in backups**; you can re-pick them.
- Anyone on your home Wi-Fi can see these photos by opening the display's address, as with the
  rest of the dashboard. Pick photos you're happy for visitors to see.

## 8. Idle screen (Display → Idle screen)
- Choose what happens when nobody touches the wall for a while (default 5 min):
  - **photo slideshow**, with clock, next event and weather
  - **stay on the dashboard**
  - **dim**
- Set what happens at night (default: dim) and how dark to dim.
- **The first tap only wakes the screen.** It never ticks a task or presses a button.

## 9. When the new tablet arrives (Lenovo Idea Tab Plus)
Within the Argos return period, run the checks in `family-display-spec.md` §3:
1. Open **Display → Device → Pen test** in Fully Kiosk and draw with the pen, then with your hand
   resting on the screen. It must show **pen** (not touch), and it must ignore your hand while the
   pen is down.
2. The pen pressure varies.
3. Settings has a charge limit.
4. Fully Kiosk wakes and dims correctly (move the PLUS licence or buy one).
5. Check that the pen's AAAA battery life is reasonable.

Then repeat step 2 on the new tablet.
